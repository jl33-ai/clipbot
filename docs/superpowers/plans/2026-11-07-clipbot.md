# Clipbot Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Clipy-identical clipboard history + snippets app for macOS that never stores passwords, encrypts everything at rest, and has no network access.

**Architecture:** A `ClipbotCore` framework holds all testable logic (secret filter, crypto, encrypted stores, capture from a pasteboard, Clipy XML, menu grouping). A thin `Clipbot` AppKit agent app (LSUIElement) wires it to the system: pasteboard polling, Carbon hotkeys, `NSMenu` popup, ⌘V synthesis, SwiftUI Settings + Snippet editor windows.

**Tech Stack:** Swift 6.4, Xcode 27, xcodegen, AppKit, SwiftUI, CryptoKit, Security (Keychain), Carbon (hotkeys), ServiceManagement. No third-party dependencies.

**Spec:** `docs/superpowers/specs/2026-11-07-clipbot-design.md`

## Global Constraints

- No third-party dependencies; no networking code anywhere.
- Deployment target macOS 15.0; bundle id `io.linus.clipbot`; product name `Clipbot`.
- Signing: Apple Development certificate of the personal team 8L83KP4DT8, Hardened Runtime on.
- Storage `~/Library/Application Support/Clipbot/` (sandbox: container equivalent), dir 0700, files 0600, `isExcludedFromBackup = true`.
- Keychain items: service `io.linus.clipbot`, accounts `clip-key` and `snippet-key`, `kSecAttrAccessibleWhenUnlockedThisDeviceOnly`, `kSecAttrSynchronizable = false`.
- AES-256-GCM (CryptoKit `AES.GCM`) for every persisted byte; dedupe tags = HMAC-SHA256 with key HKDF(clip-key, info "dedupe").
- History capacity 100, group size 10, clip size cap 20 MB (20 * 1024 * 1024 bytes, sum of representation sizes).
- Default shortcuts: main ⌘⇧V, history ⌃⌘V, snippets ⌘⇧B.
- Clip content is never logged, in any build.

## Review Focus

1. Copy from 1Password while Clipbot itself is frontmost or the source app quits instantly → still dropped via marker types (filter must check types before frontmost app, and marker check never needs data reads). Test: `testMarkerDropsRegardlessOfApp`.
2. Clipbot's own paste write is not re-recorded, but the user copying the *same* text again afterwards still moves it to top. Test: `testOwnWriteIgnoredByChangeCount` in watcher logic (`ChangeTracker`).
3. Corrupted/tampered or truncated clip file (crash mid-write, disk issue) → that entry is dropped from history, the app keeps working. Test: `testCorruptClipFileIsSkipped`.
4. Keychain key missing while files exist → files moved to `Unreadable-<yyyy-MM-dd>/`, fresh store, flag raised for a warning. Test: `testMissingKeyQuarantinesFiles`.
5. Multi-line / very long / emoji / RTL text previews → single line, ≤ 60 chars + "…", never splits a grapheme. Test: `testPreviewCollapsesAndTruncates`.

### Task 2: SecretFilter

**Files:** `Sources/ClipbotCore/SecretFilter.swift`, `Tests/ClipbotCoreTests/SecretFilterTests.swift`

**Produces:**
- `public struct SecretFilter { public var ignoredBundleIDs: Set<String>; public static let defaultIgnoredBundleIDs: Set<String>; public static let markerTypes: Set<String>; public init(ignoredBundleIDs:); public func shouldDropBeforeRead(types: [String], frontmostBundleID: String?) -> Bool; public static func looksLikeSecret(_ text: String) -> Bool }`

- [ ] Tests:
  - `testMarkerDropsRegardlessOfApp`: each of `org.nspasteboard.ConcealedType`, `org.nspasteboard.TransientType`, `org.nspasteboard.AutoGeneratedType`, `com.agilebits.onepassword` with `frontmostBundleID: "com.apple.TextEdit"` and with `nil` → true.
  - `testIgnoredAppDrops`: types `["public.utf8-plain-text"]`, each of `com.1password.1password`, `com.agilebits.onepassword7`, `com.apple.Passwords`, `com.apple.keychainaccess` → true; `com.apple.TextEdit` → false.
  - `testSecretPatterns` true for: `sk-proj-` + 40 alnum, `sk-ant-api03-` + 40, `ghp_` + 36 alnum, `github_pat_` + 60, `AKIAIOSFODNN7EXAMPLE`, `xoxb-1234-5678-abcdefghijkl`, `sk_live_` + 24, `-----BEGIN OPENSSH PRIVATE KEY-----\nabc\n-----END OPENSSH PRIVATE KEY-----`; also a key with surrounding whitespace.
  - `testNonSecretsKept` false for: `"sk-"`, `"ask-me later"`, `"Hello AKIA"`, `"ghp_short"`, a normal paragraph containing "github", a URL `https://github.com/x`, `"-----BEGIN CERTIFICATE-----"`.
- [ ] Implement. Patterns apply to the trimmed whole string (a single token, no inner whitespace) except PEM, which matches `-----BEGIN [A-Z ]*PRIVATE KEY-----` anywhere.
- [ ] Tests pass; commit `feat: secret filter`.

### Task 3: Crypto + keys + secure files

**Files:** `Sealer.swift`, `KeyStore.swift`, `SecureFiles.swift`, tests for each.

**Produces:**
- `public struct Sealer { public init(key: SymmetricKey); public func seal(_ d: Data) throws -> Data; public func open(_ d: Data) throws -> Data; public func tag(_ d: Data) -> Data }` (tag = HMAC-SHA256 with HKDF<SHA256>(key, info "dedupe", 32 bytes)).
- `public protocol KeyProviding { func existingKey(_ account: String) throws -> SymmetricKey?; func createKey(_ account: String) throws -> SymmetricKey; func deleteKey(_ account: String) throws }`; `KeychainKeyStore(service: "io.linus.clipbot")`; `InMemoryKeyStore` (public, for tests).
- `public enum SecureFiles { static func ensureDirectory(_ url: URL) throws; static func writeAtomically(_ d: Data, to url: URL) throws; static func quarantine(contentsOf dir: URL, excluding: Set<String>, date: Date) throws -> URL }`.

- [ ] Tests: round-trip; `open` of tampered byte throws; two seals of same data differ; tag is stable for same key and differs across keys; Keychain store create/existing/delete using a test-only service `io.linus.clipbot.tests` (delete in tearDown); `ensureDirectory` gives `0700` and backup exclusion; `writeAtomically` gives `0600` and leaves no stray temp files; `quarantine` moves files into `Unreadable-2026-11-07/`.
- [ ] Implement; tests pass; commit `feat: crypto, keychain keys, secure files`.

### Task 4: HistoryStore

**Files:** `ClipModels.swift`, `HistoryStore.swift`, `Tests/.../HistoryStoreTests.swift`

**Produces:**
- `public enum ClipKind: String, Codable { case text, richText, image, pdf, file, url }`
- `public struct ClipRepresentation: Codable, Equatable { public let type: String; public let data: Data }`
- `public struct ClipPayload: Codable, Equatable { public let representations: [ClipRepresentation] }`
- `public struct ClipEntry: Codable, Identifiable, Equatable { public let id: UUID; public var lastUsed: Date; public let kind: ClipKind; public let preview: String; public let thumbnail: Data?; public let tag: Data }`
- `public final class HistoryStore { public init(directory: URL, keys: KeyProviding, capacity: Int = 100) throws; public private(set) var entries: [ClipEntry]; public private(set) var recoveredFromMissingKey: Bool; public func add(_ payload: ClipPayload, kind: ClipKind, preview: String, thumbnail: Data?) throws; public func payload(for id: UUID) throws -> ClipPayload; public func moveToTop(_ id: UUID) throws; public func clear() throws }` — entries newest first. Files: `index.bin` + `clips/<uuid>.bin`.
- Dedupe tag computed over the canonical encoding of `payload` (types + data, in order).

- [ ] Tests: add then reopen a new `HistoryStore` on same dir/keys → same entries and payloads; 101 adds → 100 entries and oldest clip file deleted; adding identical payload → count unchanged, entry moved to top; `moveToTop`; `clear()` → no entries, no clip files, and `keys.existingKey("clip-key")` differs from before (rotation), old index ciphertext no longer opens; `testCorruptClipFileIsSkipped` (overwrite a clip file with garbage, reopen → that entry gone, others intact); `testMissingKeyQuarantinesFiles` (delete key from InMemoryKeyStore, reopen → empty, `recoveredFromMissingKey == true`, `Unreadable-*` dir holds old files); `testNoPlaintextOnDisk` (add text "PLAINTEXT-CANARY-123", scan every file under dir for that byte sequence → none).
- [ ] Implement; tests pass; commit `feat: encrypted history store`.

### Task 6: Capture + change tracking + menu model

**Files:** `ClipCapture.swift`, `ChangeTracker.swift`, `MenuModel.swift`, tests.

**Produces:**
- `public struct CapturedClip { payload: ClipPayload; kind: ClipKind; preview: String; thumbnail: Data? }`
- `public enum ClipCapture { static let storedTypes: [NSPasteboard.PasteboardType] /* .string, .rtf, .rtfd, .pdf, .tiff, .png, .fileURL, .URL */; static let maxBytes = 20 * 1024 * 1024; static func capture(from pb: NSPasteboard) -> CapturedClip? }` — reads only stored types from the first pasteboard item; nil if nothing stored, all-whitespace text with no other types, or size over cap. Kind priority: file > image (tiff/png) > pdf > url (URL only, no string beyond the URL) > richText > text. Thumbnail: PNG, max 32 pt edge @2x, images only.
- `public struct ChangeTracker { public init(initial: Int); public mutating func observe(_ count: Int) -> Bool /* true = new external change */; public mutating func noteOwnWrite(_ count: Int) }`
- `public enum MenuModel { static func groups<T>(_ items: [T], size: Int = 10) -> [(title: String, items: [T])] /* "1 - 10", "11 - 20" */; static func previewText(_ s: String, limit: Int = 60) -> String }`

- [ ] Tests using `NSPasteboard(name: .init("clipbot-test-\(UUID())"))`: plain string → text kind; string+rtf → richText with both reps; png image → image kind with thumbnail; file URL → file kind, preview = file name; whitespace-only → nil; 21 MB data → nil; ChangeTracker: own write not reported, later external change reported; `testOwnWriteIgnoredByChangeCount`; groups of 25 items → 3 groups titled `1 - 10`, `11 - 20`, `21 - 30` (title by slot range, not item count), last holding 5; 0 items → no groups; `testPreviewCollapsesAndTruncates` (newlines/tabs → single spaces, trimmed, 60 grapheme limit + "…", emoji not split).
- [ ] Implement; tests pass; commit `feat: capture, change tracking, menu model`.

### Task 7: Watcher + Paster + Permissions (app target)

**Files:** `PasteboardWatcher.swift`, `Paster.swift`, `Permissions.swift`, `AppDelegate.swift`, `main.swift` (replace spike).

**Produces:**
- `final class PasteboardWatcher { init(store: HistoryStore, filter: () -> SecretFilter); func start(); func noteOwnWrite() }` — 0.5 s timer; on change: `types` + `NSWorkspace.shared.frontmostApplication?.bundleIdentifier` → `shouldDropBeforeRead` → if not dropped, `ClipCapture.capture` → if text, `looksLikeSecret` → drop; else `store.add`.

Snippet: plain string only, not added to history.
- `enum Permissions { static var accessibilityTrusted: Bool; static func requestAccessibility(); static var pasteboardAccess: NSPasteboard.AccessBehavior /* macOS 15.4+ */; static func openAccessibilitySettings(); static func openPasteboardSettings() }`
- AppDelegate: builds stores at Application Support dir, shows an alert once if either store `recoveredFromMissingKey`, warns if `pasteboardAccess == .alwaysDeny`, `applicationShouldHandleReopen` → open Settings.

- [ ] Build; manual: copy text in TextEdit → appears (verify via a temporary debug count print without content, removed before commit); copy from 1Password → not recorded.
